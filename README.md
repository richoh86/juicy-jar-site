# Juicy Jar — website

The marketing, support and privacy pages for the iOS game **Juicy Jar**, served
by GitHub Pages. This repository is public only because Pages requires it; the
game's source lives in a separate private repository.

- `index.html` — landing page (App Store *Marketing URL*)
- `support.html` — how to play and FAQ (App Store *Support URL*)
- `privacy.html` — privacy policy (App Store *Privacy Policy URL*)

All three are plain, self-contained HTML with no build step and no external
requests. Images in `assets/` are the app icon and real gameplay screenshots.
